# SHADOW EMPIRE — прототип (Этап 0)

Мобильная многопользовательская «Монополия» с коррупцией/криминалом, где игровая экономика
пересчитывается по **реальным** ценам, погоде и новостям.

Полный план развития → `PLAN.md`

## Запуск

```bash
npm install
node src/server.js       # http://localhost:3000
```

Порт: `PORT=8080 node src/server.js`

## Структура

```
src/world.js    — World Engine: Yahoo Finance + Open-Meteo + Google News RSS → игровые модификаторы
src/game.js     — игровая логика: активы, доход, коррупция, криминал, следствие, боты
src/server.js   — HTTP + WebSocket, комнаты, тик раунда
public/         — мобильный клиент (vanilla JS, без сборки)
test-client.js  — прогон полного цикла через WS
```

## Как встроить на свой сайт

**Вариант А (самый быстрый).** Поднять `node src/server.js` на VPS (Fly.io / Railway / любой $5 VPS),
поставить nginx-реверс на домен и вставить на страницу:
```html
<iframe src="https://game.твой-домен.ru" style="width:100%;height:100vh;border:0"></iframe>
```

**Вариант Б.** `public/` кладём на ваш хостинг как статику, а WebSocket-URL в `public/app.js`
меняем с `location.host` на адрес игрового сервера. Нужен CORS/WSS через nginx:
```nginx
location /ws { proxy_pass http://127.0.0.1:3000; proxy_http_version 1.1;
  proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade"; }
```

## Что уже работает

- 6 реальных зон, 18 активов трёх типов: **ЛЕГАЛ / СЕРОЕ / КРИМ**
- Доход = реальная цена × плечо × война × беспорядки × погода × коррупция − палево
- Полная расшифровка «почему столько» + ссылки на настоящие статьи Reuters/WSJ/AJ
- Две валюты (белые / нал) + влияние, отмывка с комиссией
- Коррупция: взятка мэру (бьёт по всем в зоне), госконтракты, купленный инспектор, лоббизм, офшор
- Криминал: рейд/поджог, заказная проверка, крыша, спалиться перед жертвой
- Следствие: улики → дело → взятка прокурору / сдать партнёра → конфискация + арест
- Прокурор активнее, когда в реальных новостях много про коррупцию и санкции
- Мультиплеер по WebSocket: общая комната, добивание ботами до 4, синхронный конец раунда
- Реконнект, `pid` в localStorage, PWA-манифест

## Настройка баланса

`src/game.js` → `CFG` (длина раунда, старт-капитал, порог дела) и массив `ASSETS`
(`beta` — плечо к рынку, `warB` — реакция на войну, `unrestB` — на беспорядки, `wx` — погода).

Добавить зону: `src/world.js` → `ZONES` (координаты + поисковый запрос новостей),
затем активы с `zone: '<id>'`.

## Источники данных (без API-ключей)

| Данные | Источник |
|---|---|
| Нефть, золото, газ, пшеница, BTC, RUB, S&P | Yahoo Finance chart API |
| Погода (темп./ветер/осадки) | Open-Meteo |
| Война / протесты / криминал по зонам | Google News RSS |

Мир обновляется раз в 12 минут, кэшируется, при сбое источника — фолбэк на прошлый снапшот.
Клиент наружу не ходит: все игроки видят один снапшот (иначе рассинхрон и споры о честности).
